# Balance tooling

**Costs & priority:** edit [`src/game/tree.ts`](../src/game/tree.ts), then run `npm run dump-upgrades` to refresh [`balance/upgrades.json`](upgrades.json). Python sims load costs, bloom costs, island gates, and the buy order from that file via `upgrade_loader.py`.

World tuning still lives in `game_constants.py` (`WORLDS`, `PUFF_STEP`, etc.). Keep its hp/pay/mask values in step with `src/game/balance.ts` + `maskOf()` in `src/game/tree.ts`.

## Commands

```bash
python balance/feel.py         # Early-run purchases + power stats (1 buy/run)
python balance/progression.py  # Bottle-by-bottle cadence for the whole campaign
python balance/diagnose.py     # Restoration curve + dead zones
python balance/petal_feel.py   # Bloom earn vs petal shop (shared wallet)
python balance/sim.py          # Full campaign (greedy shop)
python balance/sim.py --one-buy     # Player-like single upgrade per bottle
python balance/tune.py --world 4    # Bisect one island's hp to its target minutes
npm run balance:check          # Regression gate (feel + world 0 + per-island + sync)
npm run dump-upgrades          # Refresh upgrades.json from tree.ts
```

## Currencies

- **dew** buys tree ranks (earned from mask cells).
- **blooms** (= lifetime bloomed mask cells) are a shared wallet: petals, and the
  bloom-costed island powers in the tree. `spendableBlooms()` subtracts both.
- Powers also have an **island gate** (`worldMin`): the tree only offers them once
  that island is reached, so each island arrives with its own toys.

Most powerful ranks cost **both** currencies; cheap early ranks are dew-only.

## PASS criteria

- **feel.py:** ≤2 dry runs (no workshop purchase) in the first 25 runs on world 0.
- **progression.py:** early game buys roughly one rank per bottle (sometimes more), no long stalls.
- **sim.py:** greedy shop on a fresh island. Prices should hold the shop near one rank per bottle. `check_balance.py` checks each island's minute window (world 0 is the long climb; later islands are shorter once the cloud already covers most of them).
- **tune.py:** solves `hp` for a target minute count; copy the printed hp into
  both `game_constants.py` and `src/game/balance.ts`. The globe mask is much
  larger than the flat islands (800×120) so its per-run ability bonuses do not
  trivialise the finale; keep `maskOf()` and `WORLDS` in sync.

## Paint model

`cells_per_run()` assumes each wet mask cell in the rain disc receives full `soak_per_tick` every 0.1s (same as `SaveState.paint()`). Each bottle starts on a **bare island**. A world clears only when one bottle restores ~98%. Partial progress does not carry over, so repeating a weak cloud cannot finish the island. Upgrade prices are generated by `python balance/reprice.py --write` so a bottle's income buys about one rank.

Globe masking is painted in lon/lat units: the rain radius is `rain_radius × 0.085`
and a mask cell is `(2π / cols) × (2.3 / rows)`, matching `SaveState.maskPos()`.

`playtest_factor()` scales early world-0 earn so run 1 ≈ **4 whole dew** (sparse rank-0 rain), matching real playtests—not the optimistic full-disc completion model.
